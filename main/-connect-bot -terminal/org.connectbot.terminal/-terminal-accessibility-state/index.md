# TerminalAccessibilityState

[release]\
class [TerminalAccessibilityState](index.md)

Main-thread, in-memory review state for one terminal session. Hoist this alongside the emulator to retain frozen text, selection and reading position across views. Contains no views, callbacks or accessibility node IDs. Do not share between terminals.
